# Prospection App

Plateforme de prospection intelligente et automatisée : scraping de
prospects, catalogue produit, génération de messages par IA, et
diffusion multi-canal (Email/WhatsApp).

## Architecture

Voir `docs/architecture_projet.md` pour le détail de l'architecture
(Clean Architecture / SOLID) et du modèle de données.

## Installation

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python run.py
```
